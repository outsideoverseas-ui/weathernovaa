# 🌤️ Weather App

A full-stack weather application that provides users with weather information through a simple and responsive web interface.

The project is divided into two parts:

- **Frontend** – Built using Vite and JavaScript
- **Backend** – Built using Python

---

## 🚀 Features

- 🌍 Search for weather information
- 🌡️ Display current temperature and weather conditions
- 💨 Show additional weather information
- 📱 Responsive and user-friendly interface
- ⚡ Fast frontend powered by Vite
- 🔗 Frontend and backend API integration

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Vite
- Node.js

### Backend
- Python
- Flask
- REST API
